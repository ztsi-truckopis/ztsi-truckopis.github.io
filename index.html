TruckOpis

Trip, payroll and billing system for ZTSI

What TruckOpis is

TruckOpis is the office system of ZTSI, a trucking company in the Philippines. Its staff use it to record trips and container deliveries, approve trip rates, record customer payments, run payroll, and keep track of expenses and billing.

How TruckOpis uses Google Drive

Staff can attach documents to their records, such as a container's gate pass or a bank deposit slip. TruckOpis stores these files in ZTSI's own Google Drive account, in a folder TruckOpis creates for them, so the files are kept safely outside the database and can be viewed again from inside TruckOpis.

TruckOpis asks Google only for the "drive.file" permission: it can see and manage only the files and folders it created itself. It cannot read, change or delete any other file in the Google Drive account.

Who can use it

TruckOpis is used only by ZTSI's own staff, who sign in with accounts given to them by the company. It is not offered to the public. This page is public so that anyone can read what the app does and how it handles data.
